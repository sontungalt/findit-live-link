# FindIt live link

The public link is **https://sontungalt.github.io/findit-live-link/**.

GitHub Pages serves the `live` branch. To change what visitors see, edit the site files, commit the change, and push it to `live`; GitHub Pages republishes the new version automatically.

## Printable QR source

[`qr/findit-live-link.svg`](qr/findit-live-link.svg) encodes the public link with high error correction and a four-module quiet zone. Import that SVG into your slicer or CAD tool, keep the empty border around it, and use strong visual contrast: dark raised modules on a light base (or vice versa). A roughly 80 mm square print with 0.6–1 mm raised modules is a practical starting point for phone scanning.

Do not encode a preview link—the SVG already points to the permanent GitHub Pages URL above.
